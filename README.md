### Junkbox

Junkbox est une application web qui permet a des gens de mettre des musiques en file d'attente.

Un coté admin qui permet de gérer la file d'attente et les utilisateurs. /admin
Un coté utilisateur qui permet de mettre des musiques en file d'attente. /
Un coté "spectateur" qui permet de voir la file d'attente et les musiques en cours. /display
